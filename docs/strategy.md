# Session Strategy

## Session loop

1. Read docs/progress.md and only the single roadmap step being worked on.
2. Do only that step. If a decision is genuinely open, ask no more than one or two focused questions and wait for approval where required.
3. Run the focused checks for the step.
4. Commit the completed work, push it, and confirm the deployment before moving on. Commit .agent-logs/ as it is produced.
5. Update docs/progress.md with what is done, what changed, what comes next, and open issues.
6. End the session. Start the next step in a fresh session.

## Token-saving habits

- Keep each session short and limited to one roadmap step.
- Prefer reusable components and existing project patterns.
- Seed catalogue data from a public API rather than hand-authoring a large catalogue.
- Reference file paths and focused excerpts instead of pasting whole files into prompts.
- Read only the progress document and the active step at session start.
