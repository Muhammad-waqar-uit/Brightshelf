# Brightshelf Docs

- `assignment.md`: original assessment brief.
- `roadmap.md`: approved work sequence and project rules.
- `spec.md`: Brightshelf product scope, priorities, catalogue source, and behavior.
- `design.md`: screen flows, application responsibilities, and delivery sequence.
- `strategy.md`: short-session workflow and token-saving habits.
- `progress.md`: step statuses and handoff notes.
- `tech-stack.md`: stack proposal and implementation constraints.
- `reference/`: reference-only screenshots. Do not ship these assets.
- `superpowers/plans/`: implementation plans for the approved S1-S7 slices.
- `superpowers/prompts/`: reusable roadmap prompts. These are not session logs.
